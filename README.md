# Cheshire 多 Tile SoC

基于 [PULP Cheshire](https://github.com/pulp-platform/cheshire)，集成 CVA6、Ara、FFT 加速器、私有 SPM 和共享 DMA，支持多 tile VCS 仿真与 VCU118 FPGA 构建。

以下命令在 Linux 服务器上执行。

## 1. 环境要求

| 工具 | 当前使用环境 |
| --- | --- |
| Python | 3.9 |
| Bender | 0.31.0 |
| RISC-V GCC/binutils | 支持 rv64gcv_zifencei，命令前缀 riscv64-unknown-elf- |
| VCS / vlogan | W-2024.09-SP1 |
| Vivado | 2024.2，安装 VCU118 器件和板卡文件 |
| 其他 | Git、GNU Make、wget、unzip；商业工具许可证需已配置 |

工具需加入 PATH。下文的 `vivado24` 是服务器上的 Vivado 环境包装脚本；其他环境加载 `settings64.sh` 后使用 `VIVADO=vivado`。

## 2. 拉取项目与依赖

```bash
git clone --branch dsa/multi-tile-v0 \
  https://github.com/imissyou6534/cheshire.git cheshire
cd cheshire

python3 -m pip install -r requirements.txt
git submodule update --init --recursive
bender checkout
python3 util/rom_bender.py check
```

`bender checkout` 用于全新克隆的依赖初始化；已有本地 IP 修改时不要重新检出依赖。
拉取失败时先补齐对应包的递归子模块，再继续构建。详见[依赖保护说明](docs/dependency_protection.md)。

## 3. VCS 多 Tile 仿真

准备仿真模型和编译脚本，然后运行双 tile、双 DMA 的 SPM 启动仿真：

```bash
make chs-sim-all
python3 util/run_multitile_sim.py \
  --boot spm --tiles 2 --dmas 2 --uart-tiles all
```

脚本自动编译默认程序 `sw/tests/vector_helloworld.c`、构建 VCS 模型并运行仿真，日志应包含 `PASS MULTITILE`。
模型下载失败时参考[仿真模型下载说明](docs/legacy_simulation_models.md)。

如需 ROM 启动仿真，首次运行先准备根工程 ROM：

```bash
make chs-rom-autoboot
python3 util/run_multitile_sim.py \
  --boot rom --tiles 2 --dmas 2 --uart-tiles all
```

## 4. FPGA 综合与 Bitstream

以下以 VCU118、1 tile、1 DMA、ROM 启动为例。构建会自动编译默认程序 `sw/tests/vector_helloworld.c` 并生成 ROM。

仅综合：

```bash
make chs-xilinx-multi-tile-rom-vcu118 \
  CHS_NUM_TILES=1 CHS_NUM_DMAS=1 \
  CHS_XILINX_SYNTH_ONLY=1 VIVADO=vivado24
```

完整综合、布局布线并生成 bitstream：

```bash
make chs-xilinx-multi-tile-rom-vcu118 \
  CHS_NUM_TILES=1 CHS_NUM_DMAS=1 \
  CHS_XILINX_SYNTH_ONLY=0 VIVADO=vivado24
```

按需选择其中一个命令。更换程序时追加 `CHS_ROM_APP=sw/tests/你的程序.c`。
最终 bitstream 为 `target/xilinx/out/multi_tile_rom.vcu118.bit`。重跑会覆盖同名构建目录，需保留旧报告时先备份。

更多仿真配置见 [multitile_simulation.md](docs/multitile_simulation.md)。
